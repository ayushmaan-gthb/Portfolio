# Kumar Ayushmaan — Personal Portfolio

Minimal, creative personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Typography**: Geist Sans & Geist Mono

## Current Foundation
- **Homepage Hero**: Full-screen dark canvas, elegant typography, responsive layout, and an interactive avatar with a playful blush effect on hover/touch.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
